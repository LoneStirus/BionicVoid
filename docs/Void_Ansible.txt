- STORAGE -

1. Particionamento:

$ sgdisk -Z -o -n 1:2048:+2G -t 1:ef00 -c 1:"ESP" -n 2:0:+920G -t 2:8300 -c 2:"VSP" -p /dev/nvme0n1

2. Formatação:

$ mkfs.vfat -F 32 -n "ESP" /dev/nvme0n1p1

$ mkfs.btrfs -f -L "VSP" /dev/nvme0n1p2

- MONTAGEM -

1. Subvolumes BTRFS:

$ mount /dev/nvme0n1p2 /mnt

$ btrfs subvolume create /mnt/@

$ btrfs subvolume create /mnt/@home

$ btrfs subvolume create /mnt/@cache

$ btrfs subvolume create /mnt/@log

$ umount /mnt

2. Montagem:

$ mount -o subvol=@,noatime,compress=zstd:1 /dev/nvme0n1p2 /mnt

$ mkdir -p /mnt/{home,var/cache,var/log,boot/efi}

$ mount -o subvol=@home,noatime,compress=zstd:1 /dev/nvme0n1p2 /mnt/home

$ mount -o subvol=@cache,relatime,compress=zstd:1 /dev/nvme0n1p2 /mnt/var/cache

$ mount -o subvol=@log,relatime,compress=zstd:1 /dev/nvme0n1p2 /mnt/var/log

$ chattr +C /mnt/var/cache

$ chattr +C /mnt/var/log

$ mount /dev/nvme0n1p1 /mnt/boot/efi
